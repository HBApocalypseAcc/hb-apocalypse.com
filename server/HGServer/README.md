# Servidor de Juego - HGServer

Esta carpeta contiene los archivos del servidor de juego principal de Helbreath.

## Contenido

Esta carpeta debería contener:
- Ejecutables del servidor de juego
- Archivos de datos del juego (mapas, items, NPCs, etc.)
- Scripts del servidor

## Notas

Para ejecutar el servidor, necesitará obtener los archivos del servidor de Helbreath.
Estos pueden ser obtenidos desde repositorios de la comunidad o compilados desde el código fuente.

## Referencias

- [Helbreath v3.82](https://github.com/play-helbreath/helbreath-v3.82)
- [Helbreath Xtreme Server](https://github.com/Helbreath/server)
