# Servidor de Login - LoginServer

Esta carpeta contiene los archivos del servidor de autenticación de Helbreath.

## Contenido

Esta carpeta debería contener:
- Ejecutable del servidor de login
- Archivos de configuración de autenticación
- Base de datos de cuentas (o conexión a base de datos)

## Notas

El servidor de login maneja:
- Autenticación de usuarios
- Creación de cuentas
- Gestión de personajes
- Conexión con el servidor de juego
